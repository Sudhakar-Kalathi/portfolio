Overview

A production-style SaaS financial platform designed to manage chit groups, enrollments, and payment tracking. Built with a focus on robust backend architecture, secure access, and precise financial calculations.

Engineering Highlights & Challenges

  • Layered Architecture: Designed using a clean Controller-Service-Repository-DTO structure for maintainability and strict separation of concerns.
  • Security (RBAC): Implemented stateless JWT authentication with Spring Security, enforcing role-based access control (RBAC) to separate Admin and Staff permissions across all API endpoints.
  • Performance Optimization: Resolved critical N+1 query bottlenecks in Spring Data JPA using FetchType.LAZY and custom queries to optimize database loads.
  • Financial Precision: Applied BigDecimal precision across the business logic to completely eliminate floating-point errors in financial calculations and tracking.

Frontend Integration

Built a responsive React single-page application (SPA) featuring a real-time analytics dashboard and a Day Book module for accurately tracking daily credits and debits seamlessly integrated via REST APIs.
